# Week 2 Complete

This is the canonical outcome for the Week 2 guided build. It uses semantic
HTML and a small, responsive CSS system to present all six Stage 1 fictional
films.

The buttons are deliberately visible but do not work yet. Week 3 will add
behaviour.

## How the build was prepared

The guided build had nine parts. To keep repetition from consuming the session,
the six repeated film cards were prepared in advance: at Part 5 the in-progress
`index.html` was replaced with the finished six-card version in this directory,
and the demonstration continued with the CSS.

When you build your own interface, you can write the first card by hand, check
it, and then repeat the pattern. You do not need to use these six films: choose
the content that suits your project.
